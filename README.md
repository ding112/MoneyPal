# MoneyPal

**让你的 AI 助手真正会记账。**

将从支付宝、微信或银行导出的账单文件交给 AI 整理，核对预览，确认后记入账本。再用自然语言查流水、看收支和账户余额，减少逐笔录入。

账本以标准文本保存在自己的电脑上，可以自行备份和迁移，底层基于 Beancount。

## MoneyPal 能帮你做什么

- **减少逐笔录入**：让 AI 整理导出的账单，把精力放在核对结果上。
- **写入前可以核对**：查看交易明细和疑似重复提醒，需要调整时先修改预览，确认后再入账。
- **便于长期保存**：标准文本账本可自行备份和迁移，方便持续维护个人财务记录。

## 在 DSH 中开始使用

以下步骤适用于已有 DSH Web（0.2.1-rc.2 或更新版本）的用户。环境要求和手动排查见[使用指南](docs/user-guide.md#环境要求与手动排查命令)。

**1. 安装插件**

```bash
dsh plugin --profile web add dsh-moneypal
```

**2. 打开 MoneyPal 会话**

选择准备保存账本的文件夹作为工作区，在新会话中选择 **MoneyPal** 预设。如宿主提示需要重启，按提示操作。

**3. 让助手完成首次准备**

把下面这句话发给助手：

> 帮我开始使用 MoneyPal：检查并按需准备运行环境，使用当前工作区的账本；如果还没有账本，先展示初始化内容，等我确认后创建。最后检查账本并查询一次余额。

DSH 可以代你执行环境检查与准备，并通过原生确认框创建新账本；已有符合布局的账本可直接复用。完成首次余额查询后，就可以导入账单或用自然语言记账。

## 导入第一份账单

完成对应入口的安装与账本准备后：

1. **提供导出文件**：将账单交给助手，或告知助手可读取的文件位置。
2. **核对预览**：检查日期、账户、金额、收支汇总、写入文件和疑似重复提醒；需要调整时先修改。
3. **确认入账并查询结果**：确认后由助手写入，再查询流水复核实际结果。

可以直接发送：

> 请导入这份账单，先整理交易并展示记账预览，提示可能重复的记录，等我确认后再写入。

DSH 和 Skill 的确认方式及完整操作步骤见[账单导入指南](docs/user-guide.md#如何导入账单)。

## 账本与隐私

账本文件保存在本地，但账单内容、查询结果和交易信息可能进入宿主配置的模型上下文。本地保存不代表所有处理都在离线环境中完成，使用前请了解所选宿主和模型的数据处理方式。

## 常见问题

**需要先准备什么？**

需要对应的 Agent 应用和可用的 MoneyPal 运行环境。DSH 用户查看[环境要求](docs/user-guide.md#环境要求与手动排查命令)；其他宿主从[使用方式](#start)进入对应指南。

**已有 Beancount 账本可以使用吗？**

已有符合 MoneyPal 布局的账本可以复用。先让助手检查[账本布局](docs/user-guide.md#账本布局)，不要直接覆盖或重新初始化已有账本。

**支持哪些账单文件？**

可以将从支付宝、微信或银行导出的账单文件交给助手。具体能否读取和整理取决于文件格式、内容及宿主能力，不代表支持所有银行或格式。先让助手检查文件能否读取，再核对整理结果；MoneyPal 不会自动连接银行账户同步账单。

**正式写入前如何确认？**

先核对预览，再确认写入。DSH 使用原生确认框，Skill 在对话中请求确认。疑似重复记录会提示，不会自动删除；详细确认流程和结果不确定时的处理见[使用指南](docs/user-guide.md#日常使用)。
