# 保留标准工具作为账本维护通道

DSH 预设从 `standard` 派生，在增加财务工具的同时保留 Bash、文件读写、Web、子 Agent 和工作流等标准能力。日常查询和记账约定使用财务工具，账户声明和文件组织等账本维护允许人在明确需要时使用标准工具；这是行为约束而不是强制隔离，以换取对 hledger 高级语法和异常修复的完整逃生通道。

## Considered Options

- 只暴露财务工具：隔离更强，但任何未建模的 hledger 能力都需要先扩充插件，故障恢复也更困难。
- 把所有操作交给 Bash 和文件工具：能力完整，但日常写入缺少结构化校验、统一预览和确认语义。

## Consequences

- 财务工具的安全保证只覆盖通过这些工具发起的操作；标准工具可以绕过账户检查、重复提醒和写入确认。
- 使用说明必须把标准工具定位为特殊情况下的账本维护能力，不得宣称插件形成了强安全沙箱。
- 子 Agent 可以使用只读财务工具，但不得通过财务写入工具提交交易；由根 Agent 汇总候选交易并请求人的确认。
