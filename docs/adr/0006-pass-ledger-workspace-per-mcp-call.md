# 每次 MCP 调用显式传递账本工作区

办公 Agent 的当前任务工作区决定唯一正式账本。MCP 的查询、校验和预览工具每次显式接收该绝对目录，提交则只使用预览批次已绑定的目录；服务器不保存或推断“当前账本”。这取代 ADR-0004 中由宿主环境变量绑定账本、调用方不得传路径的决定，避免同一 MCP 进程的隐藏状态把任务导向错误账本。

## Consequences

- 一个 Agent 任务只对应一个账本工作区；切换账本需要新建任务。宿主无法提供当前任务目录时，由用户明确提供绝对目录，不回退到 MCP 进程工作目录。
- `MONEYPAL_LEDGER_WORKSPACE` 仅在请求完全缺少新参数时兼容旧客户端；新配置不再设置它，成功响应会标明使用了显式参数还是旧环境变量。该兼容入口将在后续重大版本移除。
- 无效的显式目录参数直接失败，不回退旧环境变量。批次按真实账本目录隔离容量，提交目标始终继承已确认的预览。
