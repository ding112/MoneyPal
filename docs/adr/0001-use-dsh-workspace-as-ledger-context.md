# 以 DSH 工作区确定正式账本

DSH 插件不保存或询问账本路径，而是在每次工具调用时把当前会话的账本工作区解析为 `<账本工作区>/default/`，并只使用其中的 `main.beancount`。这让“打开哪个工作区”同时表达“操作哪个账本”，避免配置在会话间漂移；代价是一个工作区只能承载一个正式账本，需要切换账本时必须切换 DSH 工作区。

## Considered Options

- 在 Harness 设置中保存账本路径：更灵活，但路径与工作区可能不一致，也增加了迁移和排错状态。
- 在对话中临时设置账本路径：操作方便，但容易把一次会话中的路径误带到另一账本。
- 直接把账本工作区根目录当作账本目录：层级更少，但会把 DSH 的工作区文件和账本文件混在一起。

## Consequences

- 插件工作区只用于开发插件，不会被运行中的 DSH 自动当作正式账本。
- 正式账本必须采用固定的 `default/main.beancount` 布局；布局无效时工具明确报错，不回退到其他路径。
- v1 不提供路径配置工具，也不支持同一账本工作区中的多账本选择。
