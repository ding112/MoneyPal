# 独立账户页按已登记的 DSH 工作区读取正式账本

MoneyPal 在 DSH 左侧注册默认显示的入口，通过 `sidebar.panellist` 和 `main` 的同一面板 ID 打开独立账户页。导航遵循 DSH 的显示设置。首版一并交付导航和工作区绑定，使用户关闭所有聊天后仍能查看并刷新所选账本的余额。复用会话 ID 可以沿用余额抽屉的查询方式，但会让账户页继续依赖会话的挂载状态。

## 账本归属和访问

- 沿用 [ADR-0001](./0001-use-dsh-workspace-as-ledger-context.md) 的布局。一个账本工作区至多承载一个正式账本，主账本位于 `<账本工作区>/default/main.beancount`。账本会话和独立账户页可引用同一个工作区。
- 用 DSH `workspaceId` 标识账户页所选的工作区。候选来源是当前 Web 宿主的工作区注册表，普通会话使用过的工作区和无会话记录的工作区都适用同一布局检查。候选查询只预检约定位置，查询余额时再由现有账本引擎校验并读取所选账本。
- `ledger-candidates` 和 `ledger-balances` 沿用 Connection 的精确 `/api` 路由，只向 owner Peer 提供余额读取能力。每次余额查询均由宿主按 `workspaceId` 重新取得登记记录。余额请求只携带工作区 ID 和余额日期，候选结果只返回选择所需的标识、显示信息和状态。
- 新接口处理请求时通过 `ctx.get("workspaceRegistry")` 获取服务。服务缺失时，独立账户页显示明确的不可用状态并提供重试。
- 本决策接替 [ADR-0003](./0003-use-native-dsh-balance-drawer.md) 中余额界面的导航和账本绑定。首个独立账户页版本保留 `capability` 和 `balances` 的会话 ID 契约。Agent 财务工具由账本预设提供，按账本会话的工作区调用。

## 账本选择和刷新

- 打开页面时优先恢复手动选择的工作区 ID。没有手动选择时，只有一个候选就自动选中，有多个就显示选择器，零个就显示引导。按候选数量选择前须先取得宿主的候选结果。页面的选择始终独立于聊天会话，浏览器只持久化用户手动选择的工作区 ID。
- 已选账本暂时无法读取时，页面停留在该账本并提供重试和手动切换。登记仍有效时，可保留同一账本的旧余额，并标记数据过期和上次成功刷新时间。宿主确认登记已删除或访问被拒绝时，清空余额并显示选择器，由用户重新选择。
- 只有同名候选需要显示目录提示。宿主从各工作区目录末尾提取足以区分同名项的路径部分，例如 `个人/账本` 和 `共享/账本`。目录尾段始终省略根目录。若同名项的尾段仍相同，改用工作区 ID 区分。工作区 ID 始终是选择的依据。
- 账户页为当前面板且浏览器标签可见时，每 30 秒刷新所选账本。同一时间最多发出一个有效余额请求。离开页面或隐藏标签时停止轮询，返回时立即检查。切换账本时取消旧请求并清空其快照，迟到的结果按请求所属工作区和本次选择丢弃。

## 首版范围

用户可以选择账本、查看截至当天的资产和负债余额、刷新及重试。余额按商品分别汇总。账户管理、历史日期选择和 AI 联动由后续版本设计。

没有候选账本时，页面引导用户在 DSH 登记账本工作区。已有账本的用户登记其所在工作区。需要新建账本的用户在目标工作区打开 MoneyPal 会话，使用[现有初始化流程](../user-guide.md#在-dsh-中开始使用)预览并确认。若 `default/` 已存在但缺少主账本，页面提示检查账本目录。用户从 DSH 左侧会话列表返回聊天。

客户端沿用[现有 CommonJS 构建](../../scripts/build-client-bundle.mjs)和 DSH 提供的 React。独立页复用现有余额展示和查询逻辑，将选中账本、请求、刷新和取消交给页面的控制器。TSX 迁移单独评估。

## 宿主验收

最低支持版本 `0.2.1-rc.2` 的源码包含 [Web 工作区注册表](https://github.com/deepseek-ai/deepseek-harness/blob/687f282/packages/bundle/web-app/cordis.patch.yml)、[面板槽位](https://github.com/deepseek-ai/deepseek-harness/blob/687f282/packages/client/ui-plugin-manager/src/client/index.ts#L111-L150)和 [owner 专用精确路由](https://github.com/deepseek-ai/deepseek-harness/blob/687f282/packages/client/connection/src/rpc-host.ts#L207-L229)。首版在该版本的 Web 宿主上验证以下场景。

- 从左侧进入独立账户页。有两个候选时先显示选择器。关闭所有聊天后，仍可读取和刷新所选账本的余额。返回聊天使用 DSH 原有会话入口。
- 快速切换账本时，页面只接受本次选择发出的查询结果。刷新失败时，页面按登记和访问状态决定显示同一账本的过期余额还是清空余额。
- 调用新接口时，非 owner 请求被拒绝。宿主缺少工作区注册表时，独立页显示不可用状态。旧余额接口按会话 ID 正常工作。
