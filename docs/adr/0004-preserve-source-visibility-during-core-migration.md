# 共享核心迁移保留源码可见性差异

2026-10-28：用户明确要求核心源码私有、DSH 源码公开、MCP 源码私有，并优先减少日常迭代中的联调和版本交接步骤。后续共享核心的源码组织必须满足这些可见性要求；仓库数量作为独立取舍讨论，后续选择三仓的决定见 ADR-0005。

本轮只迁移已有功能，暂不增加资产管理或其他新功能。此范围避免同时改变业务能力与代码装配，使迁移验收能够针对已有产品行为开展。

## 影响

- 后续 ADR-0005 已选择核心、DSH、MCP 三仓；核心源码私有、固定版本核心构建包通过 npm 公开，具体交付与验收策略见 ADR-0005。
- 本决定约束源码仓库可见性，不把现有本地 JavaScript/Python 安装产物视为不可读取，也不授权更改远端权限或重写旧历史。
- MCP ADR-0010 中核心暂时复制的安排进入重新评估；新的源码与构建方案确定后再记录替代决定。产品独立版本政策继续作为现有约束。
- 本 ADR 只记录已确认的可见性、维护优先级与迁移范围，不表示仓库迁移、构建验证或发布已经完成。
